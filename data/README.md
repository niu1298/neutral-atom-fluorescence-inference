# `data/`

Nothing in this directory is tracked by Git.

```
data/
├── README.md          <- tracked
└── processed/         <- gitignored, regenerated by the exporter
    ├── paired_100ms.parquet
    ├── paired_100ms.sites.parquet
    └── paired_100ms.meta.json
```

## Where the raw shots live

Raw shot files (`*.h5`) stay under `Experiment-Data/<YYYY-MM-DD>/<sequence>/`
and are gitignored. They are read-only inputs; nothing in this repository
writes to them.

## How to regenerate `data/processed/`

```bash
python scripts/export_processed_dataset.py --config configs/paired_100ms.yaml
```

The exporter fails loudly when the raw shots are missing. It never fabricates
or substitutes data.

## Publication status

The processed table is derived from unpublished experimental data and is
**not** approved for publication. Do not commit it, and do not attach it to
public releases, until that decision is made explicitly.
